## 4. 视觉系统

### 4.1 字体

```text
正文：Source Serif Pro → PT Serif → Songti SC → 宋体 → serif。
UI：   Inter → Helvetica Neue → Arial → system-ui → sans-serif。
等宽：JetBrains Mono → SF Mono → Consolas → monospace。
加载：Google Fonts 提供 woff2，本地自托管优先；font-display: swap；失败时静默退到系统衬线。
```

```

## 5. 助手正文块级增强

### 5.1 识别规则（无回溯、保守）

按行扫描，遇到下列标记进入块模式，否则回退纯文本块：

```text
围栏代码：``` 或 ~~~，开闭必须严格成对，闭合失败回退整段为文本。
ATX 标题：# / ## / ### / #### / ##### / ######，单行。
有序列表：^\s*\d+\.\s+
无序列表：^\s*[-*+]\s+
引用：      ^\s{0,3}>
行内代码：`...`，必须同一行。
链接：[text](url) 或 <url>（仅渲染，不跳转外链）。
```

不在增强范围（避免误判）：

```text
嵌套 HTML 标签、表格、图片语法、删除线。
路径/命令/文件名识别（保留 V0.18 多关键词高亮机制，不重复造）。
```

### 5.2 增强失败策略

任何识别失败或边界模糊，立即按原文段落输出，不抛错。

### 5.3 DOM 标识

```html
<article class="message message-assistant">
  <header class="message-head">…</header>
  <div class="message-body">
    <h3>...</h3>
    <ul><li>...</li></ul>
    <pre class="code-block" data-lang="…"><code>…</code></pre>
    <p>正文段落…</p>
  </div>
</article>
```

## 8. 偏好持久化

仅两项：

```text
theme：浅 / 深，写入 <html data-theme>。
  微型脚本在 <head> 顶部读取 localStorage 同步设置，防 FOUC。

lastSelectedSessionKey：会话的 key（path 或 id）。
  进入页面后默认定位并展开该会话；找不到时回退上次状态。
```

存储位置：localStorage，key 前缀 `yuji:`。不可用时静默退到本次会话，不抛错，不污染运行数据。

## 11. 副作用与风险（含缓解）

| 类别 | 副作用 | 缓解 |
|------|--------|------|
| 性能-首屏 | Google Fonts 阻塞首屏，可能 5s+ | 本地自托管 fallback；font-display:swap；无网时全部走系统衬线 |
| 性能-滚动 | 块级增强 DOM 节点多，长会话滚动掉帧 | 超阈值（如 5000 字符）走"分段懒增强"（IntersectionObserver 进入视口再渲染），初次打开不全量 tokenize |
| 性能-内存 | DOM 节点膨胀 | 长会话默认折叠、点开后再展开；移除隐藏会话的 DOM 节点，仅保留摘要卡 |
| 误判 | 块级识别把代码块提前关闭、列表错位 | "识别失败立刻回退纯文本块"；测试覆盖：普通段落、含 `>` 的句子、含 ``` 的句子、多层嵌套列表 |
| 主题 | 双主题切换瞬间闪屏 / FOUC | 主题 CSS 变量放在 `<html>`；微型脚本在 `<head>` 顶部读取 localStorage 同步设置 `data-theme` |
| 持久化 | localStorage 被隐私模式屏蔽，切换失效 | 不可用时静默退到本次会话偏好；不抛错 |
| 数据安全 | 增强渲染被误以为是修改原文 | 顶部加一行"本页仅显示层增强，导出/复制仍是原文"；导出按钮走 rawText |
| 复制/导出 | 复制按钮把增强样式一起复制出去 | 复制走 `rawText`，按钮只复制原文 |
| 字体回退 | 用户系统没装 Source Serif，UI 降级到 Times | fallback chain：'Source Serif Pro', 'PT Serif', 'Songti SC', '宋体', serif |
| 行内弱高亮 | V0.18 多关键词高亮与新块级增强冲突 | 多关键词高亮仅作用于 `plain_text` 事件；块级增强作用于 `assistant_final` |
| 兼容 | V0.21 的搜索/备注/复制/导出不被破坏 | 不修改 PowerShell/Python server；DEMO 确认后再导入到 templates；现有 125 个 Pester 断言继续通过 |
| 文档 | 文档目录里没有 V0.21.1 占位 | 本文档即是占位；最后落实施记录 |
| 测试 | 现有 125 测试是否还能识别新模板 | DEMO 阶段先不动模板；导入时一次性同步更新测试 |
| 字体缺失 | 远程字体加载失败 → Times New Roman | font-display: swap；本地系统衬线回退；首屏不阻塞 |
| 主题切换闪烁 | 切换瞬间文字色硬切 | 颜色变量放在 html；过渡 300ms ease-in-out |
| 模板复杂度 | template.html 体积增大，可能破坏 0.21 测试 | DEMO 阶段先验；模板化前先建本地回归测试 |
| 测试覆盖率 | 块级增强需要新增不少用例 | fixture 拆成 tests/fixtures/messages/*.txt，跑每条预期与产物对比 |
