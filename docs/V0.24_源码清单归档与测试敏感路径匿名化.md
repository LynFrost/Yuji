## 1. 修改目标

V0.24 基于当前 V0.23，处理两个开源前工程治理问题：

```text
为当前 V0.23 主源码目录建立一份明确的源码归档副本。
清理 tests/Build-CodexChatIndex.Tests.ps1 中残留的真实本机路径和机构路径。
```

本版本不改变软件业务功能，不改变 UI 行为，不改变扫描逻辑，不改变运行数据结构。

本版本需要注意一个方向调整：

```text
不再把当前 CodexChatIndex 目录整体改名。
不移动当前 CodexChatIndex 目录下的 .git。
不通过目录整体改名来升版。
```

原因：

```text
当前 软件/CodexChatIndex 已经是 V0.23 之后的主源码目录。
该目录下存在 .git。
整体改名可能影响 Git 工作区、路径记录、工具配置和后续操作习惯。
```

因此 V0.24 采用：

```text
先列出当前 CodexChatIndex 下的全部源码文件。
新建 软件/CodexChatIndex_V0.23。
只把列出的源码文件按原目录结构复制到 CodexChatIndex_V0.23，作为 V0.23 源码归档。
原 软件/CodexChatIndex 目录不改名，直接就地修改为 V0.24。
```

本文档落成后不自动执行，必须等待用户确认后才进入实施。

## 6. 测试路径匿名化原则

替换真实路径时应遵循：

```text
输入夹具和预期断言必须同步改。

必须保留 .codex\sessions、.claude\projects、Claude-3p 等真实结构特征。
只匿名化用户名、机构名、具体项目编号和真实工作区路径。
```

建议统一替换表：


## 7. 是否影响软件功能

将 `tests/Build-CodexChatIndex.Tests.ps1` 中的真实路径替换为匿名假路径，不影响软件功能本身。

原因：

```text
这些路径位于测试夹具和测试断言中。
运行时代码不依赖这些具体路径。
软件扫描真实聊天记录时仍然读取用户当前系统中的实际路径。
```

会影响的是：

```text
测试断言必须同步更新。
测试路径不能过度简化，否则会降低路径转义、中文路径、空格路径的覆盖力度。
```

正确替换后，测试仍应覆盖：

```text
复制路径 toast 显示完整路径。
codex resume 命令生成。
codex -C "..." resume ... "回复" 命令生成。
claude --resume PowerShell 命令生成。
claude -p --resume PowerShell 回复命令生成。
回复框 Enter / Shift+Enter / 清空 / 草稿持久化。
```

## 8. 副作用与规避

### 8.1 归档副本和当前源码目录并存

副作用：

```text
软件/CodexChatIndex_V0.23 和 软件/CodexChatIndex 会同时存在。
如果后续误打开归档目录里的 Open-CodexChatIndex.cmd，可能运行旧版本。
```

规避：

```text
文档和说明中明确当前入口始终是 软件/CodexChatIndex/Open-CodexChatIndex.cmd。
CodexChatIndex_V0.23 只作为只读回滚参考。
```

### 8.2 复制源码清单遗漏文件

副作用：

```text
如果源码文件清单遗漏，V0.23 归档不完整。
```

规避：

```text
实施前再次用文件枚举命令确认源码清单。
排除 .git 和 temp 后，逐项复制清单中的文件。
复制后对 CodexChatIndex_V0.23 再枚举一次，与本文档清单比对。
```

### 8.3 不复制 temp 导致归档不能直接打开 HTML

副作用：

```text
CodexChatIndex_V0.23 不包含 temp/CodexChatIndex.html。
如果直接打开归档目录，首次启动需要重新构建 HTML。
```

规避：

```text
这是符合 V0.23 设计的行为。
temp 是构建产物，不应作为源码归档。
如需运行归档版本，应通过归档目录的 Open-CodexChatIndex.cmd 触发构建。
```

### 8.4 测试假路径过度简化

副作用：

```text
如果把所有路径都改成 C:\Demo，测试可能无法覆盖空格、中文、反斜杠、引号转义。
```

规避：

```text
使用 M:\Demo Workspace\Codex\示例项目_无附件 作为主匿名工作区路径。
保留 M:\Project O'Brien 等泛化测试路径。
```

### 8.5 替换断言不同步

副作用：

```text
输入路径替换了，但 Should Be / Should Match 断言没同步，测试会失败。
```

规避：

```text
按替换表统一处理。
替换后运行 Pester。
```

### 8.6 Git 工作区影响

副作用：

```text
如果整体改名 CodexChatIndex，会影响 .git 目录和工具路径。
```

规避：

```text
V0.24 不整体改名 CodexChatIndex。
只复制源码到 CodexChatIndex_V0.23。
原 CodexChatIndex 保持原位就地升版。
```
