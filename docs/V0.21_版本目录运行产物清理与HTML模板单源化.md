状态：已实施

日期：2026-06-19

## 1. 修改目标

V0.21 基于 V0.20，处理三个已经确认真实存在的改进点：

```text

将 HTML 从 Build-CodexChatIndex.ps1 here-string 中抽出为单一模板源，根治前端双副本维护问题。
```

```text
不改变来源体系。
不改变搜索、备注、复制、导出、回复框、刷新无变化快速返回等既有功能。
```

## 3. 已确认的问题

### 3.1 HTML 仍是双副本

当前仍存在两份同源 HTML：

```text
软件\软件版本_V0.20\Build-CodexChatIndex.ps1 中的 $html here-string。
软件\软件版本_V0.20\CodexChatIndex.html 独立文件。
```

已确认：

```text
Build-CodexChatIndex.ps1 约 2188 行开始内嵌完整 HTML。
Build-CodexChatIndex.ps1 约 6560 行写出 CodexChatIndex.html。
独立 CodexChatIndex.html 也保留一份完整前端。
```

问题：

```text
每次前端改动容易漏改其中一份。
如果只改独立 HTML，下次构建会被 PS1 here-string 覆盖。
如果只改 PS1，人工查看独立 HTML 时可能看不到最新源。
后续 UI 仍会持续迭代，这个维护成本会越来越高。
```

结论：

```text
有必要在 V0.21 单独偿还这笔维护性老债。
```

### 3.2 版本目录混入运行期产物

当前 V0.20 版本目录中存在运行期产物：

```text
软件\软件版本_V0.20\CodexChatIndex.sessions\
软件\软件版本_V0.20\CodexChatIndex.data.json
软件\软件版本_V0.20\CodexChatIndex.search.json
软件\软件版本_V0.20\CodexChatIndex.cache.json
```

已确认体积：

```text
CodexChatIndex.sessions: 约 2103 个 JSON，总大小约 479 MB。
CodexChatIndex.cache.json: 约 313 MB。
CodexChatIndex.search.json: 约 311 MB。
CodexChatIndex.data.json: 约 3.6 MB。
V0.20 版本快照因此超过 1 GB 级。
```

问题：

```text
版本目录膨胀。
运行数据被固化进软件版本。
清理、复制、备份都变慢。
可能把某次本机聊天详情错误地作为版本文件长期保存。
和此前约定的“运行数据放在 软件\运行数据\ 下”不一致。
```

结论：

```text
非常有必要处理，且优先级最高。
```

### 3.3 图片放大使用 window.open(data URL)

当前图片预览逻辑：

```text
openImagePreview(src) 调用 window.open(src, '_blank', 'noopener')。
```

已确认位置：

```text
CodexChatIndex.html 中 openImagePreview 使用 window.open。
Build-CodexChatIndex.ps1 的 HTML here-string 中也有相同逻辑。
```

问题：

```text
如果 src 是很长的 base64 data URL，部分浏览器可能受 URL 长度限制影响。
新标签体验和当前页面视觉不统一。
浏览器可能拦截新窗口。
```

结论：

```text
可以优化，必要性低于前两项，但同版处理成本可控。
```

目的：

```text
普通用户和开发者随手运行构建脚本，也不会再次污染版本目录。
```

## 5. HTML 模板单源化

### 5.1 推荐结构

新增模板文件：

```text
软件\软件版本_V0.21\templates\CodexChatIndex.template.html
```

或者：

```text
软件\软件版本_V0.21\CodexChatIndex.template.html
```

推荐使用 `templates\`：

```text
版本目录更清楚。
后续如果拆 CSS/JS，也有自然位置。
```

### 5.2 Build 脚本职责

`Build-CodexChatIndex.ps1` 不再内嵌整份 HTML here-string。

改为：

```text
读取模板文件。
替换少量明确占位符。
写出 CodexChatIndex.html。
```

V0.20 的 HTML here-string 中已确认存在以下 PowerShell 构建期变量。

这些变量必须在 V0.21 模板方案中完整覆盖，不能留给实施阶段再临时判断。

### 5.2.1 模板内直接占位符清单

建议占位符：

```text
{{BUILDER_VERSION}}      页面版本徽标中的版本号，例如 V0.21
{{INDEX_URL}}            JS 中 const INDEX_URL 的字符串字面量
{{TOTAL_SESSIONS}}       顶部统计“会话”
{{TOTAL_WORKSPACES}}     顶部统计“目录”
{{ARCHIVED_COUNT}}       顶部统计“归档”
{{IMAGE_REF_COUNT}}      顶部统计“含图”
{{GENERATED_AT}}         顶部统计生成时间，同时用于 title/aria-label
```

对应 V0.20 变量：

```text
$builderVersion      -> {{BUILDER_VERSION}}
$indexUrlForScript   -> {{INDEX_URL}}
$totalSessions       -> {{TOTAL_SESSIONS}}
$totalWorkspaces     -> {{TOTAL_WORKSPACES}}
$archivedCount       -> {{ARCHIVED_COUNT}}
$imageRefCount       -> {{IMAGE_REF_COUNT}}
$generatedAt         -> {{GENERATED_AT}}
```

上下文和转义规则：

```text
{{BUILDER_VERSION}}:
  HTML 文本节点。
  需要 HTML 文本转义。

{{INDEX_URL}}:
  JS 单引号字符串字面量。
  必须复用 V0.20 现有 $indexUrlForScript 转义语义。

{{TOTAL_SESSIONS}} / {{TOTAL_WORKSPACES}} / {{ARCHIVED_COUNT}} / {{IMAGE_REF_COUNT}}:
  HTML 文本节点中的数字。
  应先转为整数文本，再做 HTML 文本转义。

{{GENERATED_AT}}:
  同时出现在 HTML 文本节点、title 属性、aria-label 属性。
  文本节点用 HTML 文本转义。
  属性位置用 HTML 属性转义。
```

### 5.2.2 构建期路径变量清单

以下变量不一定直接出现在 HTML 模板里，但会影响模板生成后的数据路径或运行数据引用，也必须在 V0.21 实施时保留语义：

```text
$indexRelativePath:
  由 dataOutput 相对 outputDir 计算。
  用于生成 $indexUrlForScript。

$indexUrlForScript:
  进入模板 {{INDEX_URL}}。
  现有逻辑为：
  $indexRelativePath.Replace('\', '\\').Replace("'", "\'")

$detailRelativeRoot:
  由 detailRoot 相对 outputDir 计算。
  用于构建每条 session.detailHref。
  当前不直接插入 HTML 常量，但影响前端 loadSessionDetail(session) 请求路径。

$generatedAt:
  既进入 HTML 顶部初始统计，也进入 appData/generatedAt。
```

`$detailRelativeRoot` 不能漏掉。即使模板中不需要 `{{DETAIL_ROOT_URL}}`，构建脚本仍必须继续用它生成正确的 `detailHref`。

因此 V0.21 推荐：

```text
不要设置无用的 {{DETAIL_ROOT_URL}} 占位符。
继续在 PowerShell 构建数据阶段使用 $detailRelativeRoot 生成 session.detailHref。
模板只保留实际会插入 HTML 的占位符。
```

### 5.2.3 JS 路径转义要求

V0.20 已有 JS 路径转义：

```powershell
$indexUrlForScript = $indexRelativePath.Replace('\', '\\').Replace("'", "\'")
```

V0.21 改成模板替换后，必须保持这个语义。

要求：

```text
不要把原始 Windows 路径直接替换进 {{INDEX_URL}}。
不要只做 HTML 转义。
不要改成 JSON stringify 后又外包单引号，避免双重转义。
{{INDEX_URL}} 的替换值应等价于 V0.20 的 $indexUrlForScript。
```

建议新增函数：

```text
Convert-ToJavaScriptSingleQuotedContent
```

职责：

```text
输入任意路径文本。
输出可安全放入 JS 单引号字符串内部的内容。
至少转义反斜杠和单引号。
行为与 V0.20 $indexUrlForScript 保持兼容。
```

### 5.2.4 禁止隐式变量残留

模板文件中不应再出现 PowerShell here-string 风格变量插值：

```text
$builderVersion
$indexUrlForScript
$totalSessions
$totalWorkspaces
$archivedCount
$imageRefCount
$generatedAt
```

构建脚本应只通过显式占位符替换生成 HTML。

### 5.3 占位符规则

占位符必须满足：

```text
名字全大写。
使用双大括号。
替换前检查模板中确实存在。
替换后检查没有残留 {{...}}。
替换值必须按对应上下文转义。
```

特别注意：

```text
JS 字符串中的 URL 需要 JS 字符串转义。
HTML 属性中的文本需要 HTML 属性转义。
不要把未转义路径直接塞进 script。
```

### 5.4 独立 HTML 的定位

`CodexChatIndex.html` 变为构建输出，不再作为主要源文件。

源文件是：

```text
templates\CodexChatIndex.template.html
```

开发规则：

```text
前端改动改模板。
构建脚本生成 CodexChatIndex.html。
不要手工只改生成后的 CodexChatIndex.html。
```

### 5.5 测试要求

必须测试：

```text
构建后 CodexChatIndex.html 存在。
构建后版本号为 V0.21。
构建后 INDEX_URL 正确指向运行数据。
构建后 TOTAL_SESSIONS/TOTAL_WORKSPACES/ARCHIVED_COUNT/IMAGE_REF_COUNT/GENERATED_AT 正确进入顶部统计。
构建后没有残留 {{BUILDER_VERSION}}、{{INDEX_URL}} 等占位符。
构建后模板中不残留 $builderVersion、$indexUrlForScript、$generatedAt 等 PowerShell 插值变量。
含反斜杠和单引号的 INDEX_URL 按 V0.20 规则正确转义。
session.detailHref 仍由 $detailRelativeRoot 语义生成并可正常加载详情。
模板文件存在。
Build-CodexChatIndex.ps1 不再包含完整 <html> here-string。
```

不强制要求：

```text
本版本不拆 CSS/JS 为独立文件。
本版本不引入打包器。
本版本不引入 npm。
```

## 6. 图片页内模态预览

### 6.1 目标

将当前：

```javascript
window.open(src, '_blank', 'noopener')
```

改为页内模态预览：

```text
点击缩略图后，在当前页面打开遮罩层。
遮罩层中显示原图。
支持关闭。
不依赖新标签页。
不依赖超长 data URL 作为地址栏 URL。
```

### 6.2 模态结构建议

新增 DOM：

```html
<div id="imagePreviewModal" class="image-preview-modal" hidden>
  <button type="button" id="imagePreviewClose">关闭</button>
  <img id="imagePreviewImage" alt="">
</div>
```

也可以由 JS 动态创建。

推荐静态 DOM：

```text
便于测试。
便于样式控制。
不会每次点击重复创建节点。
```

### 6.3 打开逻辑

打开时：

```text
设置 img.src = 当前图片 src。
设置 img.alt = 图片说明。
显示 modal。
把焦点移动到关闭按钮或 modal。
```

注意：

```text
不要复制 base64 字符串到多个临时变量或 data-* 属性。
只把当前 src 赋给一个 img.src。
```

### 6.4 关闭逻辑和内存释放

关闭时必须：

```text
隐藏 modal。
清空 img.src = ''。
清空 img.alt = ''。
释放当前图片引用。
把焦点尽量还给触发的缩略图按钮。
```

原因：

```text
base64 图片可能很大。
如果关闭后 img.src 仍保留 data URL，浏览器可能继续持有内存。
```

这是 V0.21 的明确验收要求，不是可选建议。

### 6.5 关闭交互

至少支持：

```text
点击关闭按钮。
点击遮罩背景。
按 Esc。
```

暂不要求：

```text
缩放。
拖拽。
旋转。
左右切换多图。
```

第一版保持简单，避免引入复杂状态。

### 6.6 可访问性

建议：

```text
role="dialog"
aria-modal="true"
aria-label="图片预览"
```

焦点策略：

```text
打开时焦点进入 modal。
关闭时焦点回到触发按钮。
```

## 8. 副作用与风险

### 8.1 模板单源化可能引入构建错误

风险：

```text
占位符漏替换。
路径转义错误。
生成 HTML 缺变量。
测试还在断言旧 here-string 结构。
```

应对：

```text
占位符替换前后都做检查。
未替换完整时构建直接失败。
补测试确认无残留 {{...}}。
保留生成后的 CodexChatIndex.html 作为产物，但源头只认模板。
```

### 8.2 首次迁移模板会造成较大 diff

风险：

```text
Build-CodexChatIndex.ps1 会删除大段 here-string。
新增模板文件会承载完整 HTML。
diff 较大，人工 review 难度上升。
```

应对：

```text
功能改动和模板迁移尽量分段提交。
先移动 HTML 到模板并保持生成结果等价。
再做图片预览改动。
测试生成结果和 V0.20 行为一致。
```

### 8.3 清理版本目录可能影响直接打开 HTML

风险：

```text
用户直接双击 CodexChatIndex.html 时，可能看不到数据。
```

应对：

```text
正式入口仍是 Open-CodexChatIndex.cmd。
空状态提示用户通过 Open-CodexChatIndex.cmd 打开。
运行数据不删除，只迁回 软件\运行数据。
```

### 8.4 清理操作误删真实运行数据

风险：

```text
误删 软件\运行数据 下的数据会造成真实索引丢失。
```

应对：

```text
只清理 软件\软件版本_V0.21 内的运行产物。
不清理 软件\运行数据。
清理前后检查路径必须位于 软件\软件版本_V0.21。
避免使用不带边界校验的递归删除。
```

### 8.5 图片模态可能增加内存占用

风险：

```text
大 base64 图片打开后，如果 img.src 不清空，内存可能持续占用。
```

应对：

```text
关闭模态时必须清空 img.src。
不把 base64 复制到多个 DOM 属性。
不缓存历史预览图片。
```

### 8.6 图片模态可能影响键盘焦点

风险：

```text
打开图片后焦点丢失。
Esc 影响页面其他快捷键。
关闭后无法回到缩略图。
```

应对：

```text
记录触发按钮。
关闭后恢复焦点。
Esc 只在 modal 打开时处理。
```

### 8.7 测试维护成本上升

风险：

```text
当前大量测试直接读生成 HTML 并做字符串断言。
模板单源化后部分断言需要更新。
```

应对：

```text
测试继续以生成后的 HTML 为主要断言对象。
新增少量模板存在性和占位符断言。
避免测试过度绑定模板文件行号。
```

自动化测试建议覆盖：
